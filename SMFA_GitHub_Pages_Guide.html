🚀 Step-by-Step Setup
1
Create a Free GitHub Account
Go to github.com and click Sign up.
Use any email — it's completely free. You only need a basic free account.

Already have an account? Skip to Step 2. ✅
2
Create a New Repository
After logging in, click the green "New" button on the left sidebar (or go to github.com/new).

Fill in the form:
  • Repository name: type exactly smfa (or any name you want)
  • Visibility: select Public ← this is required for free GitHub Pages
  • Initialize: tick "Add a README file"

Then click "Create repository".
3
Upload Your Files
Inside your new repository, click "Add file" → "Upload files".

Drag and drop ALL of these files at once:
  • index.html
  • sw.js
  • manifest.json
  • icon-192.png (if you have it)
  • icon-512.png (if you have it)

Scroll down, add a commit message like "Upload SMFA app", then click "Commit changes".
4
Enable GitHub Pages
In your repository, click the ⚙️ Settings tab (top menu).

In the left sidebar, scroll down and click "Pages".

Under "Source", select:
  • Branch: main
  • Folder: / (root)

Click Save. GitHub will show a message:
✅ Your site is being published at https://YOUR-USERNAME.github.io/smfa/
Wait 1–3 minutes for it to go live.
5
Your App is Live! 🎉
Your permanent public URL will be:
Your SMFA App URL
https://YOUR-USERNAME.github.io/smfa/
Replace YOUR-USERNAME with your GitHub username.
For example if your username is kofiasante:
https://kofiasante.github.io/smfa/
Share this link with anyone — it works on all phones and computers worldwide. 🌍
6
Update the App (When You Make Changes)
Whenever you download an updated version of the app from Claude:

  1. Go to your repository on GitHub
  2. Click on index.html
  3. Click the pencil ✏️ icon (Edit this file)
  4. Select all text, delete it, paste in the new code
  5. Click "Commit changes"

Or simply use "Add file" → "Upload files" and upload the new index.html — GitHub will replace the old one automatically.

Once online, the Share button inside the app generates a link with your league data embedded directly in the URL. Anyone who opens it — on any phone, tablet or computer — instantly sees your league. No login needed.

❓ Common Questions
Is GitHub Pages really free?
Yes, 100% free forever for public repositories. No credit card needed. GitHub Pages gives you 1GB storage and 100GB/month bandwidth — more than enough for this app.
Will my data be saved online?
The app data (teams, players, matches) is saved in your phone/browser's localStorage — not on GitHub. Only your code is on GitHub. When you share a link, a snapshot of the data is encoded in the URL itself.
Can I use a custom domain like smfa.com?
Yes! If you own a domain, go to Settings → Pages → Custom domain and enter it. GitHub Pages supports custom domains for free. You can buy a .com domain for ~$10/year from Namecheap or GoDaddy.
What if the share link is too long?
The link encodes your full league data. If it's very long (e.g. you have many teams with large squad lists), use a free URL shortener like bit.ly or tinyurl.com to shorten it before sharing.
Can multiple admins edit the app?
Currently one admin at a time — whoever has the admin password. The data is stored locally on their device. For multi-admin support, a backend database would be needed (which requires a paid hosting plan).
How do I add my SMFA logo as the app icon?
Resize your logo to exactly 192×192 pixels and save as icon-192.png, and 512×512 as icon-512.png. Upload both to your GitHub repository. Free tools: Canva or Squoosh.
